Copilot CLI + OpenWolf Cheat Sheet

Use this repo like an AI teaching-workbench: start inside the repo, let the CLI load the repo instructions, then ask for concrete outputs like study guides, quizzes, HTML learning pages, redesigns, or fixes.

1. Fast start

cd /Users/mazdaktehrani/Downloads/tehraniD.github.io
source /Users/mazdaktehrani/Downloads/.venv/bin/activate

3. OpenWolf repo rules in this project

This repo is wired for OpenWolf. The important local files are:

  • .wolf/OPENWOLF.md — operating rules
  • .wolf/anatomy.md — file map; check this before reading lots of files
  • .wolf/cerebrum.md — learned project conventions and preferences
  • .wolf/memory.md — running memory and log
  • .wolf/buglog.json — recurring bug record

OpenWolf commands:

~/.local/bin/openwolf status
~/.local/bin/openwolf scan
~/.local/bin/openwolf daemon logs
~/.local/bin/openwolf dashboard
~/.local/bin/openwolf daemon restart
~/.local/bin/openwolf cron --help

Special OpenWolf feature:

openwolf designqc

Use it when you want screenshots and UI/design feedback.

4. What you can ask the CLI to do well here

This repo is mostly HTML educational content, so the best requests are:

  1. Create teaching material — study guides, cheat sheets, review sheets, and interactive learning pages.
  2. Revise existing pages — simplify wording, improve layout, or modernize the design.
  3. Generate assessments — NCLEX-style questions, quizzes, SATA sets, and rationales.
  4. Improve design — evaluate pages, capture screenshots, and refine visual hierarchy.
  5. Refactor or fix content — repair links, standardize layouts, and clean duplicated pages.

5. Prompt templates that work best

Make content

Create a concise cheat sheet on [topic] for beginner nursing students.
Use simple explanations first, then clinical terms.
Include: key definitions, must-know signs/symptoms, nursing priorities, and memory tricks.
Output as markdown.

Make HTML

Create a clean standalone HTML page for [topic].
Use modern styling, responsive layout, callout boxes, and quiz cards.
Audience: beginner nursing/pre-med students.

Edit an existing page

Improve /Users/mazdaktehrani/Downloads/tehraniD.github.io/[file].html.
Keep the content accurate, but simplify the wording and improve the visual hierarchy.

Make questions

Create 10 NCLEX-style questions on [topic].
Mix standard MCQ and SATA.
Explain why each wrong answer is wrong.

Review or fix

Review this repo for broken links, duplicated pages, and inconsistent navigation.
Make the fixes directly.

6. Best workflow

  1. Start in the repo.
  2. Run /init.
  3. Ask for a specific deliverable.
  4. Use /diff to inspect changes.
  5. Use /undo if needed.
  6. Use /share if you want an exported report.
